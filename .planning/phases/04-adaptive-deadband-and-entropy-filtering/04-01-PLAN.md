# Plan 04-01: Adaptive Regime Deadband & Epistemic Entropy Filtering

## Objective
Elevate the out-of-sample directional hit rate of the Valence signal engine from 71.4% towards 78–82% by introducing two zero-cost, high-leverage quantitative filters:
1. **Epistemic Entropy Gating**: Reject ambiguous and high-entropy headlines ($H_2(\mathbf{p}) > 0.96$) to eliminate false whipsaws on mixed news releases.
2. **Volatility-Adaptive Regime Deadband ($\theta_{\text{band}}(t)$)**: Dynamically scale the neutral deadband based on rolling sentiment dispersion ($\sigma_{\text{sentiment}}$) to demand higher statistical conviction during volatile macro regimes.

## Implementation Tasks

### 1. Mathematical Formulation (`src/signal_engine/ema.py`)
- Implement `calculate_shannon_entropy(p_bull: float, p_bear: float) -> float`: Normalized directional binary entropy $H_2 \in [0.0, 1.0]$.
- Implement `calculate_adaptive_deadband(ema_series: pd.Series, base_threshold: float = 5.0, window: int = 20, gamma: float = 0.25) -> pd.Series`: Clamped dynamic threshold in $[5.0, 15.0]$.
- Implement `resolve_directional_stance(ema_val: float, entropy: float, threshold: float) -> str`: Assigns `BULLISH`, `BEARISH`, or `NEUTRAL` based on the joint conditions $\text{EMA} \ge +\theta$ and $H_2 \le 0.96$.

### 2. Ingestion Pipeline & Telemetry (`src/main.py`)
- In `score_sentiment`:
  - Extract $P(\text{Bullish})$ and $P(\text{Bearish})$, compute $H_2(\mathbf{p})$.
  - If $H_2(\mathbf{p}) > 0.96$ (ambiguous/conflicted information), clamp score and categorize as `Neutral`.
  - Pass `"Entropy": round(entropy, 4)` in output dictionary.
- In `record_forward_signal`:
  - Evaluate directional stance using `resolve_directional_stance` with trailing dynamic threshold.

### 3. Forward Evaluation Ledger (`src/signal_engine/forward_tester.py`)
- Upgrade `compute_metrics_from_dataframe`:
  - Calculate rolling sentiment volatility $\sigma_t$ per ticker.
  - Compute dual hit rate metrics:
    a) Baseline static hit rate ($\pm 5.0$ threshold) for backward compatibility (71.4%).
    b) Adaptive hit rate ($\theta_{\text{band}}$ + entropy gating) reflecting optimized regime tracking.
  - Return telemetry metrics: `directional_hit_rate_pct`, `adaptive_hit_rate_pct`, `neutral_filtered_vol_pct`, and `average_entropy`.

### 4. Public Track Record Card (`src/ui/components/ledger.py`)
- Render dual performance telemetry in the public track record collapsible card:
  - Surface the upgraded adaptive hit rate badge (e.g. `79.2% ADAPTIVE HIT RATE`).
  - Provide an explanatory breakdown pill showing noise filtering volume efficiency (e.g. `18% Filtered Noise → +7.8% Hit Rate Alpha`).

### 5. Automated Test Coverage (`tests/unit/`)
- Create `tests/unit/test_entropy_filter.py`:
  - Test entropy boundary conditions ($p_b=0.5 \implies H=1.0$, $p_b=1.0 \implies H=0.0$).
  - Test numerical stability ($\epsilon = 10^{-9}$, avoiding $\log(0)$).
- Create `tests/unit/test_adaptive_deadband.py`:
  - Test dynamic threshold expansion under high volatility ($\sigma \ge 12.0$).
  - Test threshold clamping strictly within $[5.0, 15.0]$.
  - Test stance assignment under diverse (EMA, entropy, threshold) permutations.
- Update `tests/unit/test_forward_tester.py` to assert presence and validity of adaptive metrics.
