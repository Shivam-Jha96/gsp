# Plan 02-02: Pipeline Hardening, Model Fallback Registry & OKF Governance

## Objective
Harden Gemini model registry in `src/knowledge_engine/okf_updater.py`, remove retired endpoints, implement macro rule diff validation, gate automated OKF modifications behind Pull Requests in GitHub Actions, and enrich database schema with complete audit columns.

## Tasks
1. Update `src/knowledge_engine/okf_updater.py` with dynamic Gemini model inspection and active model priority (`gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-3.x-flash`). Remove retired `gemini-1.5/2.0-flash`.
2. Add diff-guard validation `validate_macro_rule_diff()` preventing rules shrinkage > 35%.
3. Update `.github/workflows/update_okf.yml` with `peter-evans/create-pull-request@v6` to gate macro rules updates behind PR review instead of direct master branch push.
4. Add audit columns (`published_at`, `scored_at`, `okf_version_hash`, `model_version`) in `src/database/schemas.sql` and `scripts/add_audit_columns.sql`.
5. Update `src/main.py` with git commit hash resolution and resilient backward-compatible insert fallback for unmigrated database environments.
