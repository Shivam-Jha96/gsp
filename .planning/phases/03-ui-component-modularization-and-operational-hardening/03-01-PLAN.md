# Plan 03-01: UI Monolith Decomposition into Modular Components

## Objective
Decompose the 2,380+ line monolith `src/ui/app.py` into cleanly scoped, single-responsibility modules in `src/ui/components/` and `src/ui/styles.py`, while preserving all permanent dark theme CSS variables, `@st.fragment` partial reactivity, local-storage sync, and query param state persistence.

## Tasks
1. [x] **Extract Styling & Themes (`src/ui/styles.py`)**:
   - Move all dark theme CSS blocks, responsive font definitions (`IBM Plex Sans`, `JetBrains Mono`, `Montserrat`), and CSS variables into `src/ui/styles.py`.
   - Expose `get_theme_css()` and `inject_global_styles()`.
2. [x] **Extract UI Components (`src/ui/components/`)**:
   - `header.py`: `render_header_banner`, `render_usp_banner`, `render_regulatory_disclaimer`.
   - `toolbar.py`: `render_filter_toolbar`, `render_segmented_filter`.
   - `analytics.py`: `render_analytics_surface`, Plotly chart generation, metric cards, sentiment gauges.
   - `feed.py`: `render_live_intelligence_feed`, headline cards, sentiment pills.
   - `ledger.py`: `render_forward_test_ledger_section`.
3. [x] **Orchestrate `src/ui/app.py`**:
   - Refactor `app.py` into a concise application entry point (~200 lines).
   - Ensure imports maintain hot-reload resilience across Streamlit Cloud runtimes.
4. [x] **Verification**:
   - Verify all Streamlit components render without import errors or visual regressions.
   - Run unit test suite to guarantee zero regression across the system (57/57 tests passing).
