# Quick Task Plan: Reorganize Knowledge Regions Directory

**Task Slug:** `261009-k01-reorganize-knowledge-regions`  
**Date:** 2026-10-09  

## Objective
Reorganize the `knowledge/` directory into a clean hierarchical structure:
`knowledge/regions/<region_name>/` containing `constituents.okf.json` and `macro.okf.md` for each region (`india`, `japan`, `uk`, `us`).

## Context & Invariants
- `market_registry.json` is the single source of truth for `okf_file` and `constituents_file` paths.
- All code modules (`src/config/market_registry.py`, `src/main.py`, `src/knowledge_engine/okf_updater.py`) load these paths dynamically via `market_registry.json`.
- Preservation of file content and git history using `git mv`.
- Documentation sync across `README.md`, `docs/architecture_and_workflow.md`, `docs/wiki_home.md`, and `.planning/codebase/STRUCTURE.md`.

## Execution Steps
1. Create `knowledge/regions/{india,japan,uk,us}` directories.
2. Relocate files using `git mv`:
   - `knowledge/india_constituents.okf.json` -> `knowledge/regions/india/constituents.okf.json`
   - `knowledge/india_macro.okf.md` -> `knowledge/regions/india/macro.okf.md`
   - `knowledge/japan_constituents.okf.json` -> `knowledge/regions/japan/constituents.okf.json`
   - `knowledge/japan_macro.okf.md` -> `knowledge/regions/japan/macro.okf.md`
   - `knowledge/uk_constituents.okf.json` -> `knowledge/regions/uk/constituents.okf.json`
   - `knowledge/uk_macro.okf.md` -> `knowledge/regions/uk/macro.okf.md`
   - `knowledge/us_constituents.okf.json` -> `knowledge/regions/us/constituents.okf.json`
   - `knowledge/us_macro.okf.md` -> `knowledge/regions/us/macro.okf.md`
3. Update `src/config/market_registry.json` with the new relative paths.
4. Update `scripts/update_constituents.py` to recursively find constituents files or load from registry.
5. Update `tests/unit/test_classifier_and_registry.py` to assert both `okf_file` and `constituents_file` exist on disk.
6. Run unit tests (`python -m unittest discover tests`).
7. Update documentation suite per `gsp-doc-sync`.
8. Complete GSD state updates and record atomic git commit.
