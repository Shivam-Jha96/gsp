# Quick Task Summary: 261005-j14

## What Was Done
Implemented durable pipeline execution lifecycle telemetry and replaced the static RSS headline timestamp on the Streamlit dashboard header with the live completion timestamp of the last successful run of the Global Macro-Sentiment Pipeline (`src/main.py`).

1. **Schema Layer (`src/database/schemas.sql`):**
   - Added DDL for `pipeline_runs` (`id`, `pipeline_name`, `status`, `started_at`, `completed_at`, `duration_seconds`, `items_polled`, `items_scored`, `metadata`).

2. **Telemetry Engine (`src/database/telemetry.py`):**

   - Wrapped `__main__` execution inside `track_pipeline_run("macro_sentiment_pipeline", db_client=db_client)`.
