# Quick Plan: 261005-j14

## Goal
Replace the static RSS headline timestamp in the dashboard header banner with the live completion timestamp of the last successful run of the Global Macro-Sentiment Pipeline (`src/main.py`).

## Tasks

### Task 1: Telemetry Persistence Layer
- **Files:** `src/database/schemas.sql`, `src/database/telemetry.py`
- **Action:**
  - Add `pipeline_runs` table DDL and composite index `(pipeline_name, status, completed_at DESC)` to `src/database/schemas.sql`.
  - Create `src/database/telemetry.py` containing `ensure_pipeline_runs_table`, `track_pipeline_run` (context manager), `get_latest_successful_pipeline_run`, and `format_pipeline_freshness`.
- **Verify:** Run mock DB tests confirming schema creation and lifecycle tracking.

### Task 2: Pipeline Telemetry Integration
- **Files:** `src/main.py`
- **Action:**
  - Import `track_pipeline_run` and `get_db_client` in `src/main.py`.
  - Update `run_ingestion_pipeline()` to return `(polled_count, scored_count)`.
  - Wrap pipeline execution in `track_pipeline_run("macro_sentiment_pipeline", db_client=db_client)`.
  - Record payload counts and ensure zero-opex deduplicated runs record `items_scored=0` while still advancing completion timestamp.
- **Verify:** Syntax check `python -m compileall src/main.py`.

### Task 3: Dashboard Freshness Badge Integration
- **Files:** `src/ui/app.py`
- **Action:**
  - Import `get_latest_successful_pipeline_run` and `format_pipeline_freshness` from `database.telemetry`.
  - Update `load_data()` to query `latest_pipeline_run` from PostgreSQL.
  - Update header action card HTML to render `UPDATED {time_display_str}` with relative time `({relative_str})` and rich hover tooltip.
  - Fall back gracefully to `df_signals['timestamp'].max()` if no pipeline run records exist.
- **Verify:** Syntax check `python -m compileall src/ui/app.py`.

### Task 4: Unit Testing & Verification
- **Files:** `tests/unit/test_telemetry.py`
- **Action:**
  - Add unit test suite verifying telemetry tracking, failure isolation, zero-payload handling, and formatting edge cases.
  - Run full test suite: `python -m unittest discover tests/unit`.
- **Verify:** All unit tests pass.
