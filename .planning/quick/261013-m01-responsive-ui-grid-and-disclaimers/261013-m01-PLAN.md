# Quick Task Plan: Fix Variable Screen Distortions in Dashboard Grids & Disclosures

**Task Slug:** `261013-m01-responsive-ui-grid-and-disclaimers`  
**Date:** 2026-10-13  

## Objective
Remediate responsive layout distortions on variable screen sizes (specifically mobile and tablet devices as captured in user telemetry screenshots):
1. Resolve the orphaned 5th metric card and asymmetric empty hole in the Forward Test Ledger 5-metric micro-KPI grid (`.ledger-metrics-grid`).
2. Fix distorted multi-line word-wrapping in regulatory badges (`.regulatory-subcard-badge`), un-aligned callout pill banners (`.regulatory-callout-pill`), squashed bullet text next to chips (`.regulatory-bullet-item`, `.reg-chip`), and bottom-bar overlaps with Streamlit Cloud floating widgets in the Regulatory Disclosures section (`.regulatory-notice-card`).

## Context & Invariants
- Institutional Obsidian Dark Mode styling (`#020617` background, `#0f172a` cards, `#10b981` / `#ef4444` accents).
- High visual balance and symmetry across desktop (>= 960px), tablet (600px - 959px), mobile (380px - 599px), and narrow viewport (<= 380px) breakpoints.
- Zero changes to quantitative logic or backend APIs; purely presentation-tier responsive CSS enhancements in `src/ui/styles.py`.

## Execution Steps
1. **Forward Test Ledger (`.ledger-metrics-grid`) Responsive Grid Architecture:**
   - Desktop (>= 960px): `grid-template-columns: repeat(5, minmax(0, 1fr))` for a single, symmetrical row of 5 micro-KPIs.
   - Mobile / Tablet (<= 959px): `grid-template-columns: repeat(2, minmax(0, 1fr))` with `.ledger-metric-card.highlight` spanning `grid-column: 1 / -1`. This transforms the 5th card ("Directional Hit Rate / Accuracy") into a prominent hero accuracy banner below a clean 2x2 grid, eliminating the asymmetric void.
   - Narrow mobile (<= 380px): `grid-template-columns: 1fr` with `grid-column: auto`.
   - Prevent badge wrapping: Add `white-space: nowrap !important; flex-shrink: 0 !important;` to `.ledger-tag`.
   - Responsive ledger governance strip: Stack columns on mobile (`<= 768px`).
   - Responsive ledger footer bar: Stack dot and source info cleanly on mobile.

2. **Regulatory & Research Disclosures (`.regulatory-notice-card`) Responsive Layout:**
   - Prevent badge text breakage: Add `white-space: nowrap !important; flex-shrink: 0 !important;` to `.regulatory-subcard-badge`, `.regulatory-badge`, `.regulatory-pill`, and `.regulatory-mono-tag`.
   - Subcard header resilience: Ensure `.regulatory-subcard-header` flex-wraps with `gap: 8px` and title has `font-size: clamp(0.72rem, 2.5vw, 0.76rem)`.
   - Full-width callout banners: Set `.regulatory-callout-pill` to `display: block; width: 100%; box-sizing: border-box; text-align: center;` so all warnings stretch uniformly across cards.
   - Bullet item readability:
     - Desktop (> 768px): Maintain row layout, align chips with `min-width: 88px; text-align: center;`.
     - Mobile (<= 768px): Switch `.regulatory-bullet-item` to `flex-direction: column; align-items: flex-start; gap: 3px;` so explanation paragraphs use 100% available width rather than being pinched beside wide chips.
   - Grid and card container sizing: Set `.regulatory-grid` to `grid-template-columns: 1fr` on mobile (`<= 768px`).
   - Prevent bottom-bar overlap with Streamlit Cloud floating controls: Add `margin-bottom: 40px !important;` to `.regulatory-notice-card` and stack bottom bar items on mobile.

3. **Analytics KPI Column Height Handling:**
   - Ensure `.kpi-column-container` and `.kpi-card` gracefully unbind fixed flex-stretching on stacked mobile viewports (`<= 768px`).

4. **Verification & Testing:**
